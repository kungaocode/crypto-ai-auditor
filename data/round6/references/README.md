# R6 Secure References

This directory contains fixed-commit security-control snippets that are kept
outside the R6 training artifacts.

`report_secure_references.jsonl` is generated by:

```bash
python3 scripts/build_report_secure_references.py --emit
```

The seven entries were approved by the project owner as non-training
`secure_reference` material. They are not `vulnerable=true` positive samples,
not Detect negatives, and not Triage findings. Every row remains
`verified=false` and `training_eligible=false`; use them only for repair
references, comparative review, or a later human relabeling pass.

The companion machine-audit source is
`data/round6/candidates/report_secure_controls.jsonl`. Eight report candidates
whose recommended role was `exclude` remain only in that audit file.
